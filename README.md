# ASIZSC Converter – PCB Design

## Overview

This project presents the schematic and PCB design of an Advanced
Switched-Inductor Z-Source Converter (ASIZSC) developed using KiCad.

The converter incorporates three IRFP460 MOSFETs, MUR640 diodes,
switched-inductor networks, capacitors, and output filtering.

The PCB was designed with a focus on proper power routing, component
placement, high-current paths, and interfacing with an external
gate-driver circuit.

## Key Features

- Advanced Switched-Inductor Z-Source Converter topology
- 3-MOSFET switching stage
- External gate-driver interface
- Custom footprints for large inductors
- Power-oriented PCB routing
- Through-hole and SMD components
- 3D PCB visualization
- Gerber files prepared for fabrication

## Tools Used

- KiCad
- KiCad Schematic Editor
- KiCad PCB Editor
- KiCad 3D Viewer

## Hardware

- IRFP460 MOSFET × 3
- MUR640 diode × 2
- 80 µH inductors × 2
- 1 mH inductors × 2
- 33 µF capacitors × 2
- 330 µF output capacitor
- 144 Ω load resistor
- External gate-driver interface
